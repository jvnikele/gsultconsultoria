# Bio da Gsult

Site estático com os contatos atualizados. Não precisa instalar dependências nem executar build.

## Publicar

1. Extraia o ZIP.
2. Envie o conteúdo extraído para a raiz do repositório. O arquivo index.html deve ficar na raiz, ao lado de style.css e da pasta assets.
3. Ative o GitHub Pages para publicar a branch que contém esses arquivos, usando a pasta raiz.
4. Use o endereço fornecido pelo GitHub Pages na bio do Instagram.

## Arquivos

- index.html: textos e links de contato.
- style.css: cores, fontes e layout responsivo.
- assets/: logo e fontes locais.
- .nojekyll: permite servir diretamente os arquivos estáticos.
